## 方法：五板斧

排查按"先便宜后贵、先硬后软"的顺序进行，详细展开见主 WP 小结（含流程图）：

1. **元数据审查**——EXIF / PNG tEXt / XMP，正向找生成参数残留（ComfyUI、SD WebUI），反向查格式合规性（斜杠日期 = 注入痕迹），还能用完整厂商链反证真图；
2. **魔数校验**——文件头 vs 扩展名，一条命令必拿分；
3. **溯源字符串检索**——对原始字节搜 `ContentProducer` / C2PA，不能用图片查看器；
4. **同源图对齐 diff**——同场景多张图对齐后逐像素差分，抓增删物体和涂抹残影；
5. **视觉细节兜底**——手、脸、文字乱码、重复元素，放大检查放最后。

核心纪律是**软硬证据分家**：硬证据（参数残留、溯源标识、魔数不符、格式违规、畸形手指、diff 出的物体消失）可单独定罪；软证据（ELA 异常、蜡像感、噪点不均）必须两条以上互证且无合理替代解释。

## 工具环境

复盘复现只需 Python 3 + Pillow：

```bash
pip install pillow
```

用到的技术：PNG chunk 结构解析（struct）、ELA 误差水平分析（PIL 重压缩差分）、RGB 特征筛选 + 网格聚类（"路牌蓝"定位）、同源图对齐 diff（偏移搜索 + 逐像素差分）、EXIF 解析（PIL Exif）。
